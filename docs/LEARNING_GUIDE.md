# Learning Guide

## What you are learning

1. Browser automation with Playwright
2. HTML parsing with BeautifulSoup
3. Data cleaning with pandas
4. CSV/XLSX export
5. Markdown reporting
6. Raw-data retention for debugging
7. Environment isolation with `.venv`
8. Pipeline logging and validation

## Recommended progression

Web scraping → raw storage → validation → cleaning → relational database → ETL/ELT → orchestration → BI.

The important engineering habit is to preserve the raw layer so parser failures can be reproduced without repeatedly requesting the source.

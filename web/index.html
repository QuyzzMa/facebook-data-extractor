Lấy dữ liệu Facebook gọn gàng & an toàn.

Mở một trang Facebook bạn được phép xem, cuộn, rồi xuất ra CSV, XLSX và Markdown. Hai chế độ: posts (bài đăng kèm like / bình luận / chia sẻ) hoặc commenters (tên + URL người bình luận).

Tính năng

🧩

Hai chế độ

posts (mỗi dòng 1 bài) hoặc commenters (mỗi dòng 1 người bình luận).

🔐

Đăng nhập linh hoạt

Cookie đã lưu (storage_state), gắn Chrome/Edge thật (cdp), hoặc profile Playwright.

🧠

DOM mới + cũ

Đọc bài theo data-ad-preview="message" và số liệu qua aria-label, có fallback.

🎛️

Cuộn có kiểm soát

max_scrolls + giới hạn thời gian; tự bấm "Xem thêm bình luận" để lấy thêm người.

🔔

Thông báo truy cập

Cảnh báo khi trang yêu cầu đăng nhập, tham gia nhóm, chờ duyệt, giới hạn độ tuổi…

📤

Xuất 3 định dạng

CSV (utf-8-sig), XLSX (tự chỉnh cột) và báo cáo Markdown.

Chạy dữ liệu thật

Nhập URL một trang Facebook bạn được phép xem. Tính năng này cần chạy server cục bộ (vì cần trình duyệt + phiên đăng nhập): python server.py rồi mở http://127.0.0.1:8000. 


        

          

        

      

    


    

      

        
Luồng chạy

        
    
          
  1. 1
    Nhập URL
    Chọn trang Facebook mỗi lần chạy.
    2. 
          
  2. 2
    Đăng nhập
    Dùng phiên đã lưu (cookie) — không lưu mật khẩu.
    3. 
          
  3. 3
    Cuộn & bóc tách
    Cuộn có giới hạn, bấm "Xem thêm bình luận", parse DOM.
    4. 
          
  4. 4
    Xuất kết quả
    CSV + XLSX + báo cáo Markdown trong output\.
    5. 
        

      

    


    

      

        
Cách chạy

        

          
# cài đặt một lần
py -3 -m venv .venv
.\\.venv\\Scripts\\python.exe -m pip install -r requirements.txt
.\\.venv\\Scripts\\python.exe -m playwright install chromium

# chạy (hỏi URL; Enter để dùng mặc định)
.\\.venv\\Scripts\\python.exe main.py

# làm mới phiên khi hết hạn
cookie.bat   &&   run.bat
